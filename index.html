Hi, I’m James Jason, a developer passionate about technology and coding.

A Computer Engineering graduate. I like understanding how things actually work, not just getting them to run networks, databases, systems, all of it. For my thesis I built Aegis of Cyberprotection, a hardware-enforced USB and network security system using Python, Raspberry Pi, and machine learning to catch threats in real time. A DICT cybersecurity expert and a licensed ECE engineer validated it, which still feels good to say out loud.

I'm familiar with web development, database design, software development, and troubleshooting network, hardware, and PC issues in general. On my own time I've built a few full stack projects: a coffee shop management system with role-based logins, a travel booking platform with OAuth and payment integration, and a LAN based inventory system with proper access control. Mostly Java, Python, PHP, Flask, MySQL, and Firebase, depending on what the project called for. Right now I'm looking for an entry level IT role where I can put these skills to use, keep learning, and actually contribute to a team.
